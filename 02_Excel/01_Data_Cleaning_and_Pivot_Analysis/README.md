# Excel Data Cleaning and Pivot Analysis

## Project overview

This workbook uses a deliberately messy sales export to demonstrate data preparation and analysis in Excel.

## Workbook contents

- `Messy_Data` — original raw export containing inconsistent formats and data-quality issues.
- `Cleaned_Data` — standardised dataset for analysis.
- `Pivot tables and charts` — pivot-style summaries and charts.
- `Lookup_Aggregation` — lookup/reference, conditional logic and aggregation exercises.
- `pivot charts with slicers` — sales summaries with slicer-based filtering.

## Cleaning summary

The workbook's own cleaning summary reports:

- 261 source rows with an Order ID in the raw sheet (including junk).
- 240 clean orders in the cleaned sheet.
- 21 rows removed as duplicates and junk.
- 279 blank cells in the raw data range A:N.
- 0 blank cells left in the cleaned data range A:M.

## Skills demonstrated

- Data cleaning and standardisation.
- Handling inconsistent dates, names, categories, statuses and numeric formats.
- Removing duplicate/junk records.
- Lookup and aggregation formulas.
- Summary analysis, charts and slicers.

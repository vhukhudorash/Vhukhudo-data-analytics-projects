# Bucudo | Data Analytics Portfolio

Welcome to my data analytics portfolio. This repository brings together practical projects completed while developing my skills in **Excel, SQL Server and Microsoft Power BI**.

  **Microsoft Data Analysis with SQL, Excel and Power BI Professional Certificate** and hands-on projects focused on preparing data, exploring information, building reports and communicating findings.

## Technical skills demonstrated

- **Excel:** data cleaning, standardisation, lookup and aggregation formulas, summary analysis, charts and slicer-based reporting.
- **SQL Server (T-SQL):** relational database creation, primary and foreign keys, filtering, sorting, aggregations, joins, subqueries, conditional logic, data manipulation and transactions.
- **Power BI:** interactive dashboards, KPI cards, charts, slicers, report pages and written insights/recommendations.

### Excel

**Data Cleaning and Pivot Analysis** — [Open Excel project folder](02_Excel/01_Data_Cleaning_and_Pivot_Analysis/)

The workbook contains a deliberately messy sales export and a cleaned dataset, plus pivot-style summaries, charts, lookup/aggregation exercises and a slicer-based analysis sheet. The workbook's cleaning summary reports 261 source rows with Order IDs, 240 cleaned orders and 21 rows removed as duplicates or junk.

### SQL

**HR Employee Analytics** — [Open SQL project folder](03_SQL/01_HR_Employee_Analytics/)

A SQL Server project using three related tables: `Departments`, `Employees` and `TrainingRecords`. It demonstrates relational database design, data exploration, aggregation, joins, business questions and safe DML practice using a transaction and rollback. The sample data is fictional.

## How to view the projects

- **Power BI:** download a `.pbix` file and open it with Power BI Desktop.
- **Excel:** download the `.xlsx` workbook and open it with Microsoft Excel. Some slicer and data-validation features may behave differently in non-Excel spreadsheet applications.
- **SQL Server:** follow the instructions in the SQL project's README and run the numbered `.sql` scripts in order using SQL Server Management Studio (SSMS).
